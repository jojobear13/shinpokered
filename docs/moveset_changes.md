# Moveset changes

What every Pokémon learns in PK30 against the original Red and Blue: level-up
moves, starting moves and TM/HM compatibility, then the TM list, the new
moves and the old moves whose data changed. Each change is marked **S** if
Shin Pokémon (the base of this fork) already made it, or **P** if PK30 made
it. Generated by `tools/moveset_changes.py` from the source.

In each list: `+Move 12` is new, at level 12; `Move 20→12` moved from
level 20; `−Move (was 20)` is no longer learned. Starting moves are those a
Pokémon has at level 1.
