Learnsets" sheet of `Gen1_Remaster_Learnset_Audit.xlsx` (design brief, Gen 9
rules pass, part 9). Each line: species, move, where it was (`start` = a
starting move, `-` = not learned) and where it is now, and the sheet's
decision. Every row was applied, CONDITIONAL ones included.

them ask for a category change (Razor Leaf special), which Gen 9's rules
don't allow, so they stay as they are.
